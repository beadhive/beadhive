# Gateway experience conformance proof

The hermetic proof vendors the `bh-gw-p7v` contract corpus from
`beadhive/beadhive-gateway` at commit
`4ed2425b9860006f692fddfaa19cef4ec2a656f4`. The local corpus lock records the
SHA-256 digest of every imported schema, case matrix, and upstream source lock.

Run the proof from the repository root:

```console
uv run pytest -q tests/test_gateway_read.py -k \
  'pinned_gateway_experience_corpus or pinned_failure_policy or digest_valid_mixed or runtime_factory_installs_validated_catalog or runtime_live_mode'
```

The proof validates an authenticated generated response against the pinned
schema and positive capability matrix. It also exercises authentication,
authorization, and source-unavailable failures against the pinned error schema;
proves that live mode has no generated fallback; rejects client-selected
scenarios; and verifies that a digest-valid artifact with mixed lane provenance
fails before the listener can become ready.
