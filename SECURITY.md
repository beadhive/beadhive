# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

The preferred way to report a vulnerability is through GitHub's private vulnerability
reporting: go to the [Security tab](https://github.com/beadhive/beadhive/security) of this
repo and use **"Report a vulnerability"**. This opens a private advisory visible only to the
maintainer and lets us coordinate a fix and disclosure timeline before any details go public.

If that option isn't available to you for any reason, open a
[GitHub Issue](https://github.com/beadhive/beadhive/issues) with the minimal detail needed to
start a conversation (no exploit details or proof-of-concept) and ask for a private channel —
the maintainer will follow up.

## Supported versions

This project is pre-1.0 and moves quickly; only the latest released version on PyPI is
supported. Please upgrade to the latest release before reporting an issue.
